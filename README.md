# Interactive Algebra Tricks Course

An interactive algebra course built with React, Vite and KaTeX for mathematical notation.

## Run locally

With Node.js and npm installed:

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Build and preview

```bash
npm run build
npm run preview
```

## Project guide

- [src/AlgebraicTricks.jsx](src/AlgebraicTricks.jsx): course interface and learning content.
- [src/main.jsx](src/main.jsx): React entry point.
- [package.json](package.json): scripts and dependencies.
- [vite.config.js](vite.config.js): build configuration.
